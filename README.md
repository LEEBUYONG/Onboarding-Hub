# 상시 온보딩 허브 — 초안

팀스파르타 AX교육팀 강사·보조강사 상시 온보딩 허브의 초안 웹페이지입니다.
노션 「🟠 상시 온보딩 기획안」과 그 하위 세 문서를 원본으로 생성했습니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 초안 웹페이지. 외부 의존성 없는 단일 파일이라 더블클릭으로 열립니다 |
| `챕터문제.md` | 챕터·원본 문서 링크·체크리스트·퀴즈 42문항의 유일한 데이터 원본 |
| `기획.md` | 구조·화면·데이터 모델·보안·운영 정책 |
| `SKILL.md` | 기획.md + 챕터문제.md 를 웹페이지로 옮기는 빌드 지침과 완료 기준 |
| `robots.txt` · `<meta name="robots">` | 검색엔진 수집 차단 (초안 공개 URL 보호용 최소 조치) |

## 보는 법

`index.html` 을 브라우저에서 엽니다. 서버가 필요 없습니다. GitHub Pages 에 올리면 그 주소로도 열립니다.

- 시작 화면에서 이름·역할·정산 유형을 고르면 내 트랙이 만들어집니다.
- 파트마다 **영상 → 문서 → 퀴즈 → 체크리스트** 순서로 진행하며, 문서 단계에서는 원본 문서를 하나씩 열어 「읽었습니다」에 직접 체크해야 숙지 버튼이 열립니다.
- 문서 단계의 「퀴즈 출제 범위 미리보기」로 어떤 문항이 나오는지 미리 볼 수 있습니다(정답은 퀴즈에서).
- 「기존 활동자로 체험」을 켜면 온보딩이 끝난 상태로 시작해 **변경사항(숙지 항목)** 화면을 볼 수 있습니다.
- 파트 화면 아래의 「이 파트 바로 완료 처리」는 리뷰용 버튼입니다. 실서비스에는 없습니다.
- 상단 「어드민」은 목업입니다. 「퀴즈 문항 관리」에서 전체 문항·보기·정답·해설을 펼쳐 볼 수 있습니다.
- 진행상황은 메모리에만 있습니다. 새로고침하면 사라지므로 필요하면 「내보내기」로 파일 저장 후 「불러오기」 하세요.

## 고칠 때

- 챕터 순서·요약·문서 링크·체크리스트·퀴즈 문항 → `챕터문제.md` 만 고치고 `index.html` 상단의 `DOCS` · `PARTS` · `QUIZ` 상수를 다시 맞춥니다.
- 화면·기능·정책 → `기획.md` 를 먼저 고친 뒤 코드에 반영합니다.
- `{{BIZ_DEADLINE}}` `{{CONTRACT_CUTOFF}}` `{{VIDEO_URLS}}` 는 운영 확정값이 나올 때까지 그대로 두고, 화면에는 「확정 예정」 배지로 표시됩니다. 강사 포털 주소는 포털 이용 가이드에 공개된 값을 넣었습니다.
- 레벨·시급 기준 안내 문서는 금액이 있어 허브에서 링크하지 않습니다. 「강사 포털 > 내 자격 (로그인)」 항목으로 대체되어 있습니다.
- 노션 링크는 팀 워크스페이스 주소(app.notion.com)입니다. 외부 강사가 열려면 각 페이지가 웹에 게시되어 있어야 하며, 게시 주소(teamsparta.notion.site/…)로 바꿔 두는 것이 안전합니다.
